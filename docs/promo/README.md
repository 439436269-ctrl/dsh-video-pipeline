## 生成

```sh
node tools/make-promo-sources.mjs   # 草稿 → 发布源（去掉平台说明/目录节，表格→列表，围栏→引用）
```

`make-promo-sources.mjs` 带发布安全断言：不得残留表格行、代码围栏、有序列表、行内反引号、目录节、`<url>` 自动链接。

## 踩过的坑（知乎/公众号发布链路）

1. **`{{TOKEN}}` 式的引擎语法超纲**：知乎的注入器只认 h1-h3 / `-` 列表 / `>` 引用 / 分隔线 / 加粗链接图片；表格、代码围栏、有序列表、行内反引号都会变成字面文本。所以发布源必须预处理。
2. **清空编辑器必须断言**：上游脚本 `Ctrl+A → Delete` 不校验，一旦选区不在编辑器里，随后的 paste 会变成**追加**（实测把 8 节粘成 16 节），而成功判据 `h2 ≥ 1 && >300 字` 在追加时同样成立，于是它报 FIXED。
3. **正文里有图时，点编辑器容器可能落在图上**，全选选不到文本 → 先点 `div[data-block]` 里**有文字**的块。
4. **`insert-images.cjs` 的 `dir` 是滚动方向**：靠顶部的锚点用 `-1`、靠底部的用 `1`；用错一律报 `anchor not found`，容易误导去查锚点字符串。
5. **图片右下角会被平台水印盖住**：知乎水印贴图片右下角，所以关系图底部留了 96px 空白带（画布 1356×728），左下角放仓库链接、右下角刻意留空。
6. **公众号封面不能信引擎自报**：裁剪页「确认」超时会导致封面其实没绑上，而引擎仍报 `coverOk: true`；权威判定是重开草稿读回图床背景图，用 `fix-cover.cjs` 兜底。
7. **同名素材会被秒选**：公众号素材库按文件名命中同名图时直接选旧图 → 换封面务必用新文件名（`-v2`）。
